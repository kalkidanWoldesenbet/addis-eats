# Addis Eats

A food-ordering frontend for Addis Ababa. Browse a menu, filter by category, view a dish, build an order, and check out through a validated form.

## Screens
- `/` — Home, today's specials
- `/menu` — Fetched dishes, filterable by category
- `/menu/:id` — Single dish detail
- `/cart` — Order lines and running total
- `/checkout` — Validated form, guarded by sign-in

## Stack
React + Vite, React Router
